# 人がシナリオを作るための操作ガイド

アプリケーション0.4.0。保存するシナリオは従来のversion 3。計算の意味は [data-model.md](data-model.md) と [simulation.md](simulation.md) を参照する。直交線・Relative / Fixedノード・図上CDFは [別の設計案](time-axis-design.md) であり、今回の実装には含めない。

## 空の文書から作る

1. 「新規」でタイトル・時間単位・全期間を指定する。現在の文書は文書一覧に残る。
2. 「登場主体」を追加する。Actor行の＋ボタンからも活動を追加できる。
3. 「活動を追加」で主体、開始条件、活動名、所要時間、到達する成果を入力する。開始State・Task・結果Stateをまとめて作る。
4. 結果Stateを選び「次の活動を追加」を使うと、そのStateを次の開始条件として再利用する。
5. Stateの「＋接続」またはツールバー「接続」で他のState・活動へ結ぶ。同ActorのState間はTask、別Actorへの接続は作用線となる。候補の色とツールチップで時間逆行・暗黙依存の循環を確認できる。
6. 到達したいStateを選び「達成目標にする」。図に目標旗が現れる。複数目標のAND/ORと期限はシミュレーション設定で指定する。
7. 「実行準備」で未設定の分岐・目標などを確認し、対象の編集画面へ進む。

上部の作成ガイドと「練習する」は、登場主体・活動・相互作用・目標・実行準備の順で操作を案内する。ショートカットを知らなくても、ボタンと図上ハンドルで作成できる。

## 活動・途中の成果・分岐

活動の詳細には名前・開始・終了・基準所要時間がある。「開始を固定」「終了を固定」「開始・終了を直接指定」で調整方法を選べる。通常到達先のない活動は最終分岐を終了位置として編集する。開始・所要時間の変更では分岐点の基準進捗を保持して再配置する。独立に分岐時刻を編集することもできる。

途中の出力には「途中の成果を追加」を使う。通常の到達先を持つTaskを二つに分割して、その間にStateを作る。技術の関連付け・中止条件は両方へ引き継ぐ。追加開始条件・品質入力は前半に置く。FIXの品質保持率は前半へ引き継ぎ、後半を1として元の劣化を重複適用しない。途中の品質の仮定は分割後に見直す。

CDFを分割する根拠はないため、CDF付きTaskでは「固定時間に戻して分割」の明示選択が必要で、分割後のCDFはそれぞれ再設定する。分岐点と同時刻、通常到達先のないTaskの分割は拒否する。

分岐追加時に「確率」「外部作用」「図示だけ」を選ぶ。確率分岐には通常継続の残り確率を表示する。通常到達先がない最終確率分岐は合計1が必要。Task編集の分岐表で結果名・到達先・確率・遅延をまとめて扱う。

StateからTask上の任意地点に接続すると、作用を受ける分岐・結果・作用線を一回の適用で作る。既存の白丸への接続では結果を選ぶ。前提に反する作用元時刻や循環を作る接続は拒否し、理由を表示する。

通常の接続編集も、適用前は仮の図として扱う。キャンセル・Escで仮の線を取り消し、自動保存やUndo履歴に残さない。新規作用線は既定で実行対象となり、説明用にする場合は実行をOFFにする。読み込んだ既存文書のOFF設定は変更しない。

## 時刻を一括して整合させる

State時刻の変更には二つの方針がある。

| 方針 | 処理 |
| --- | --- |
| 後続の所要時間を保って移動 | 後続State・分岐・結果を移動し、受け側・作用線の基準時間も整合させる |
| 後続の基準時刻を維持 | 後続位置を保持するため、FIXの所要時間・伝搬時間を調整する |

通常のドラッグ・左右キーは前者、Shift付き操作は後者。ドラッグ中は移動後の位置を仮表示し、負の所要時間などが生じると理由を表示する。複数Stateを移動しても、後続への同じ移動量を二重に加算しない。

Task所要時間・作用の伝搬時間を変更すると、AND/OR合流・分岐・暗黙の開始依存を含め、関係する基準時刻を一回の変更として更新する。適用前の差分を表示する。必要なら全期間を延長する。無効な編集は部分適用せず、Undo一回で戻せる。

**CDFの点の時間は、基準時刻の編集では自動変更しない。** 計算上の所要時間分布と図の基準窓は別に確認する。名前・備考だけの編集では、他のStateの時刻を再計算しない。

文書設定で時間単位を変更する場合は「実時間を保って換算」と「数値を維持して単位を変更」を選ぶ。換算ではState、Junction、結果遅延、伝搬時間、CDF点、Mission期限、全期間、スナップ、表示範囲を同じ係数で更新する。全期間・スナップは1e-9以上で保存する。

## 合流・依存・技術

State編集ではAND/ORと入力の基準到着をプレビューできる。ANDの早着待ちとORの後着は区別し、後着で品質を変更しないことを表示する。図にも複数入力のAND/ORを表示し、右クリックで切り替えられる。

Task選択時に、追加開始条件・品質入力・中止条件を図上で表示する。各設定の「図から条件を選ぶ」ではStateをクリックして条件を選べる。分岐作用の発生元Stateを選ぶと、対象活動の開始待ちも表示する。これらは通常の作用線や品質計算と混同しない。

「技術を関連付け」から新しい技術を登録して、その対象へ一度に関連付けられる。技術の名称・成熟状況・TRLと、Task/作用線の時間・品質は別の設定であり、技術登録だけでCDFや保持率は変更しない。

## CDFを調整する

Taskも作用線もFIX/CDFを選び、共通の編集操作を使う。

- グラフの点をドラッグして所要時間と累積達成確率を編集する。時間の順序と確率の単調性を保持する。矢印キーでの編集と数値表も使える。
- 表の「入力品質」は曲線の入力q、「達成確率」はp、「品質保持率」は各時間のqである。
- ひな型から仮のCDFを作り、既存Task/作用線のCDFを複製できる。仮置き・計測・推定の区別と根拠は備考に記録する。
- 「低品質・高品質を設定」はq=0と1の曲線を作る。初期の形は同じなので、実際の品質による差を自分で設定する。
- プレビュー用qは数値とスライダーで調整する。上流品質や保存される固定qを上書きしない。
- 未達確率は1−最終p。到達したq=0と不達は別である。

編集画面のタイトル・適用・キャンセルは画面内に固定し、長い表だけをスクロールする。

## 分析と変更前の結果

全CDF分析のカードから対象を編集できる。再分析すると前回の結果と基準成功率の差を表示する。ランキングは入力qの単独介入の効果であり、技術の成熟度変更やCDFそのものの改善効果と読み替えない。

名前・備考・色・技術・表示範囲などの変更では計算済み結果を保持する。時刻・品質・CDF・接続・分岐・目標など計算条件が変わると、現在の図への適用を解除し、変更前の結果を旧入力スナップショットと一緒に残す。変更前の結果はJSON出力できる。新旧の結果を取り違えないよう区別する。

## 文書・保存・診断

「文書」で複数文書の切替、別案としての複製、保存時点の復元を行う。「保存時点」は文書ごとに最新20件をブラウザに保存する。復元前の状態も保存時点に残す。文書の切替で前のシナリオを上書きしない。

ブラウザ内の保存領域は同じオリジンのlocalStorage。JSON出力とは別で、別ブラウザへの共有やブラウザの保存領域を消す操作に備える場合はJSONを保存する。保存に失敗すると「自動保存できません」を表示する。

問題のあるJSONは原文を保持して診断する。「読み込み診断」の「時刻の整合を修正する案を確認」で差分を確認し、適用すると元JSONを修正前の保存時点に残す。参照切れ・循環・不正なCDFを勝手に削除して修正することはしない。時刻だけで修正できなければ詳細エラーを出す。

検索はActor・State・Task・作用線・技術の名前、備考、IDを対象とする。候補には主体と基準時刻を示す。選択へ移動、前後State、関連先への移動、クリック可能な全体概観を使える。Actorの移動は上下端で並べ替え、中央で親子化となり、ドロップ位置を仮表示する。

詳細パネルには、複製される範囲と、削除時に巻き込まれる活動・作用・技術関連付けの件数を事前に表示する。範囲外の開始・品質・中止条件への参照は複製時に維持する。

## 開発確認

`npm test` はモデル・作成操作・DOM操作・CDF・分析・保存を確認する。実ブラウザの確認は `npm run test:browser`。PlaywrightとChromiumを別途用意する。`CHROMIUM_EXECUTABLE` で実行ファイル、`CHROMIUM_ARGS_FILE` で引数のJSON配列、`QA_OUTPUT_DIR` で確認画像の出力先を指定できる。通常の利用者にはこれらの依存は不要。

ブラウザ確認では空の文書から活動・分岐・目標・保存時点を作り、CDFグラフ編集・シミュレーション・全CDF分析・対象編集を実行する。1440 / 1024 / 640px幅で確認し、画面全体の横はみ出しとJavaScriptエラーを検査する。

## 共通時間軸と図上CDF

1. 活動を追加すると▼開始点と●成果を作成します。既存ノードは編集の「時間種別」か詳細パネルで切り替えます。H+はシナリオ開始からの経過時間で、秒・分・時間は文書の単位です。
2. Fixedはその時刻までに条件が揃った場合だけ成立します。Relativeを動かすと入力の時間関係を調整します。複数入力では調整する入力を選べます。他の入力が時刻を拘束している場合は変更を診断し、文書に適用しません。
3. 図の「CDF」で設定／結果を切り替え、選択したTask・作用だけ、または全対象を表示します。設定CDFのqはプレビュー用です。曲線のダブルクリックで性能編集を開けます。
4. 「CDF全期間」で裾まで表示し、カーソルでその時刻の累積確率を確認します。線の水平部分だけが時間です。縦の距離に所要時間の意味はありません。
5. Simulationを実行して結果CDFを表示すると、未開始・未達を含む全試行を分母とした通常完了／実到着／ノード成立の分布を読めます。Fixedの成立CDFは指定時刻でのステップになります。
6. ファイルメニューの「共通時間軸デモ（図上CDF・固定時刻）」で動作を確認できます。SVG/PNGにも同じ表示モードを出力します。

日時としての09:30やD-Day入力は今後の段階です。現在はH+経過時間を入力してください。
