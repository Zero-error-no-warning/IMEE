# サンプル

- coastal / submarine / research: シナリオのみのMission Thread。途中報告・指令をStateで出し、迎撃を分岐点へ接続する。階層・技術表示を比較できる。
- tutorial/coastal / submarine / research: 小規模な識別・通信・妨害の教材。分岐結果を明示する。実行設定がないため、Simulationには適切な設定を加える。
- simulation.json: 時間CDF・品質保持率・AND合流・分岐作用を持つ実行例。
- llm-example.json: LLM向けの完全なシナリオ例。
- comparison-v1: 旧設計の凍結資料。version 3の仕様例として使わない。

すべての現行サンプルは架空の仮定。図の時刻・技術成熟度は実在装備の性能評価ではない。JSONとブラウザ内ファクトリを同時に更新する。
