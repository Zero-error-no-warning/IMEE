# ブラウザでの確認手順

Node.js + jsdomの操作テストは、ピクセル配置・ネイティブのヒットテスト・OSファイル選択を再現しません。次を実ブラウザで確認してください。

1. `index.html` を開く。モード切替ボタンがなく、詳細パネルは閉じている。上部に追加・保存・検索、下部に時間範囲の操作が収まる。
2. 空白のダブルクリックでState追加、Stateのダブルクリックで編集。本体ドラッグ、Ctrl / ⌘ + ドラッグの複製、両端の伸縮を確認。
3. State下側の丸から同じActorのStateへ接続してTransitionが作られる。別ActorのStateならInteractionになり、予定Transitionなら妨害になる。途中にモード切替は不要。
4. 丸→接続先を順にクリックする方法、右クリック→「ここから接続」も確認。Escで取消。ドラッグ中に仮の接続線が見える。
5. 「＋ グループ」で親を作り、右クリックから子Actor・子グループを追加。複数階層を作る。自身・子孫を親に指定できない。
6. Actor名を別Actor行の中央へドラッグして子にする。上下端へドロップしてその前後に移動。移動プレビューが見え、子孫も移動する。
7. 左の三角でグループを閉じ、子孫のStateと関連する作用の非表示件数を確認。展開してすべてが復元される。閉じた子孫を検索すると展開される。
8. ズームしてもSVGの横幅・Actor列が変わらず、横スクロールが出ない。下のスライダー・前後矢印・時間範囲の数値指定で移動。「全体」で全期間に戻る。
9. 拡大した状態でStateを追加・移動・伸縮し、表示された時刻と編集値が一致する。Space + ドラッグ、Ctrl / ⌘ + ホイール、Shift + ホイールも確認。
10. 詳細パネルの開閉でタイムライン幅が変わらない。右クリックから編集・削除・階層変更・子追加・グループ解除・SVG出力を操作できる。画面端でもメニューがはみ出さない。
11. 1366×768、狭いウィンドウ、低いウィンドウでツールバーが収まり、必要に応じて折り返す。ページ全体にスクロールはなく、Actor一覧だけ縦にスクロールする。ポップアップとパネルは画面内に収まる。
12. Undo/Redoで接続・階層・グループ削除を往復。JSON保存→読込で親子関係と折りたたみ状態が復元される。
13. 拡大・グループ折りたたみ中にSVGを書き出す。単独で開いて全期間・全階層が表示される。エディタの表示時間と折りたたみ状態は変わらない。
14. 右上メニューの「潜水艦グループのサンプル」を読み込み、潜水艦の下にソナー・魚雷が表示される。読込はUndo可能。

検証状況：75件のモデル・DOM操作テスト通過。通常・拡大・グループ折りたたみのSVGを画像化して確認。検証用ブラウザの `file:` アクセスが環境ポリシーで拒否されているため、実ブラウザでのE2Eと全体UIの目視確認は未実施です。
