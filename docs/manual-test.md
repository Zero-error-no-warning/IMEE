# ブラウザでの確認手順

自動テストはNode.js + jsdomを使います。jsdomはピクセル配置、ネイティブのヒットテスト、OSのファイル選択を再現しないため、次を実ブラウザで確認してください。

1. `index.html` を直接開く。ネットワークを切った状態でも5つのActorとサンプルが表示される。
2. 新規Actorを追加。空白をダブルクリックしてStateを追加。State自身をダブルクリックして編集ダイアログが開く。
3. Stateを横にドラッグしスナップすること、左右端をそれぞれ伸縮できること、Ctrl / ⌘ + ドラッグで1件だけ複製されることを確認。
4. 接続のないStateを別Actorへ移す。左のActor名をドラッグして並べ替える。
5. 2つのStateをTモードでつなぐ。別Actor同士をIモードでつなぐ。右側の丸からのドラッグでも接続する。
6. 予定Transitionを用意し、Bモードで作用元Stateからその矢印を選ぶ。阻止時刻と妨害後のStateを指定し、×・作用線・結果への点線を確認。
7. 時間を逆行する編集を試し、理由が表示されてデータが元に戻ることを確認。
8. Ctrl / ⌘ + Z、Redoで複数操作を往復。Actor削除の連鎖も一操作で戻る。
9. JSONを保存し、リロード後も同じ状態が復元される。JSON読込で置き換え、Undoで読込前に戻る。不正なJSONで元データが失われない。
10. 拡大して縦横スクロール。時間目盛とActor名が追従して見える。Spaceドラッグと中ボタンドラッグも確認。
11. 横・縦スクロールした状態からSVGを書き出す。単独で開き、Actor名・時間軸がずれず図全体が表示される。
12. 検索でStateへ移動。因果強調で阻止の対象と妨害後の状態が強調対象に含まれる。
13. 幅の狭いウィンドウでツールバーが折り返し、詳細パネルを閉じてキャンバスを操作できる。
14. マウスを使わずボタン・ダイアログ・右クリックメニューのキーボード操作を確認。Stateはクリック選択後に矢印キーで移動・Shiftで伸縮できる。

実装時の検証：モデル・DOM操作の自動テスト通過、出力SVGの画像化による確認済み。検証用ブラウザの `file:` アクセスが環境ポリシーで拒否されたため、上記の実ブラウザ手動確認は未実施です。
