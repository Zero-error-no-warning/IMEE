# ブラウザでの確認手順

Node.js + jsdomの操作テストは、ピクセル配置・ネイティブのヒットテスト・OSファイル選択を再現しません。次を実ブラウザで確認してください。

1. `index.html` を開く。接続種類のモード切替ボタンがなく、詳細パネルは閉じている。上部に追加・保存・検索、下部に時間範囲の操作が収まる。
2. 空白のダブルクリックでState追加、Stateのダブルクリックで編集。本体ドラッグ、Ctrl / ⌘ + ドラッグの複製、両端の伸縮を確認。
3. Alt / Optionを押してState本体から同じActorのStateへドラッグして接続してTransitionが作られる。別ActorのStateならInteractionになり、予定Transitionなら妨害になる。途中にモード切替は不要。
4. State選択→Cキー→接続先クリックの方法、右クリック→「ここから接続」も確認。Escで取消。ドラッグ中に仮の接続線が見える。
5. 「＋ グループ」で親を作り、右クリックから子Actor・子グループを追加。複数階層を作る。自身・子孫を親に指定できない。
6. Actor名を別Actor行の中央へドラッグして子にする。上下端へドロップしてその前後に移動。移動プレビューが見え、子孫も移動する。
7. 左の三角でグループを閉じ、子孫のState件数と外部Interactionの束ね線を確認。展開してすべてが復元される。閉じた子孫を検索すると展開される。
8. ズームしてもSVGの横幅・Actor列が変わらず、横スクロールが出ない。下のスライダー・前後矢印・時間範囲の数値指定で移動。「全体」で全期間に戻る。
9. 拡大した状態でStateを追加・移動・伸縮し、表示された時刻と編集値が一致する。Space + ドラッグ、Ctrl / ⌘ + ホイール、Shift + ホイールも確認。
10. 詳細パネルの開閉でタイムライン幅が変わらない。右クリックから編集・削除・階層変更・子追加・グループ解除・SVG出力を操作できる。画面端でもメニューがはみ出さない。
11. 1366×768、狭いウィンドウ、低いウィンドウでツールバーが収まり、必要に応じて折り返す。ページ全体にスクロールはなく、Actor一覧だけ縦にスクロールする。ポップアップとパネルは画面内に収まる。
12. Undo/Redoで接続・階層・グループ削除を往復。JSON保存→読込で親子関係と折りたたみ状態が復元される。
13. 拡大・グループ折りたたみ中にSVGを書き出す。単独で開いて全期間・全階層が表示される。エディタの表示時間と折りたたみ状態は変わらない。
14. 右上メニューの「潜水艦グループのサンプル」を読み込み、潜水艦の下にソナー・魚雷が表示される。読込はUndo可能。

検証状況：114件のモデル・DOM操作テスト通過。通常・拡大・グループ折りたたみのSVGを画像化して確認。検証用ブラウザの `file:` アクセスが環境ポリシーで拒否されているため、実ブラウザでのE2Eと全体UIの目視確認は未実施です。

## Technology / 編集拡張の追加確認

15. Ctrl/⌘+Clickで複数Actorと複数Stateを選択。選択追加・解除、空白からの矩形選択、Ctrl/⌘併用の矩形追加を試す。
16. 複数Stateを上下・左右へドラッグ、複数Actorを親変更。関係が不正になる場合は一括で元に戻る。
17. Actor / Group / 複数StateでCtrl/⌘+D。子孫と内部接続・技術Bindingは複製され、外部Interactionが増えない。
18. Ctrl/⌘+C / X / VとUndo。重複IDがなく、コピー元とは独立した内部接続を持つ。文書変更後は古いクリップボードが貼り付けられない。
19. Actorを複数選択して「まとめる」。右クリックまたはCtrl/⌘+Shift+Gで解除。Stateを持つ親のデータは残る。
20. Technology Viewで技術追加・TRL・status編集。4種類の要素へBindingし、解除・保存・再読込を試す。
21. 各Viewと表示設定、レーン高さを試す。再読込後も倍率・時間範囲・折りたたみ・順序が保持される。
22. 同種の3本の作用があるGroupを閉じ、×3のProxyを確認。詳細で元の3本を確認。展開で元の時刻へ戻る。
23. 接続ドラッグ中のState・予定Transitionの強調、カーソル直下の強調を確認。Transitionの周辺でもドロップできる。
24. Transition編集で開始／終了を変更。所要時間が前後State境界の差として変化する。
25. Technology / Gapサンプルの敵「離脱成立」を選択。各候補経路を選び、Gapより上流の強調が途切れ、未成熟技術の依存先を確認できる。
26. 「遅延する介入案」を選択すると遅すぎる警告。検討案は×を追加しない。技術のstatus変更で経路評価が更新される。
27. 混雑する作用ラベルは省略され、選択で全文に戻る。攻撃赤太線、指令青緑、情報濃灰破線、観測紫破線を見分けられる。

上の実ブラウザ確認項目は未実施です。追加機能はモデル・jsdomイベントテスト、および出力SVGの画像化で確認しています。

## コンパクト表示・PNGの確認

28. Stateの丸い接続ハンドルがなく、通常ドラッグは移動、Alt / Option＋ドラッグは接続になる。Ctrl/⌘ドラッグの複製も引き続き使える。Altを途中で離しても接続を完了・取消できる。
29. Actor列・目盛・行間がコンパクトで、技術の吹き出しに背景と枠線がある。複数レーン、長い技術名、狭い幅でも状態や接続先を追える。全文はTooltip・Inspectorで確認できる。
30. PNG出力後のファイルを画像ビューアーで開き、文字、吹き出し、矢印、白背景を確認する。ズーム・折りたたみ中でも全期間・全階層が出力され、編集画面の状態は変わらない。

PNGの自動テストはImage/Canvasを置換して入出力経路・寸法・エラー処理を検証しています。ブラウザによる実際のPNG描画・ダウンロードの実機確認は未実施です。SVGからの静的画像化は別途確認しています。
