# version 2 手動確認

Node.js 24で`npm ci && npm test`を実行した後、以下をChrome / Firefox / Safari等で確認する。自動テストはjsdomによるDOM操作を含むが、実ブラウザE2Eではない。PNGのImage / Canvasは代替実装であり、以下の画像検証を代替しない。

## 起動と読み方

1. `index.html`をfile://で直接開く。サーバー・CDNへのアクセスを必要としないこと。
2. 基本サンプルが敵UUV・海底センサー・管制・味方UUV・魚雷の5Actorで、全期間が60分であること。
3. 14分の発見、17→18分の報告、30→31分の指令、40分の発射、46分の命中が旧図と一致すること。
4. 離脱成立Taskが44〜52分で、46分の白丸から無力化へ分岐し、予定の離脱完了は52分にあること。
5. 階層サンプルは潜水艦の子にソナーと魚雷があり、折りたたんでも接続の時刻が変わらないこと。
6. 技術例の協調音響識別・水中指令通信の不足、54分の遅延案を確認すること。
7. 「表現デモ（捜索・識別・通信）」を別メニューから開き、通常Task・一致／不一致・通信失敗後の再送を確認すること。Undoで元の比較用サンプルに戻れること。
8. State・Task・因果編集に「予定・案」がなく、旧JSONでもタグやフィルタ・分析条件として働かないこと。破線・点線による意味表現がないこと。

## 編集と接続

1. Actor行の空白をダブルクリックし、timeだけを持つStateを追加する。
2. 点をドラッグ、左右キーで移動。リサイズハンドル・期間欄がないこと。隣のStateを越えて不正なTaskになる編集は拒否され、元の文書が保たれること。
3. 同じActorのStateからAlt / Option＋ドラッグして別Stateへ接続。Task編集が開くこと。C→クリック、右クリック→ここから接続でも同じ結果になること。
4. 別ActorのStateへ接続し、正の因果・負の因果を切り替える。常時モード切り替えが不要であること。
5. StateまたはTask途中から別Taskの途中へ接続。ポップアップのTask端点timeがマウス位置とスナップに合うこと。複数因果を同じtimeにして白丸が1つになること。
6. 接続中だけState / Taskが強調され、Taskの細い線から少し外れても接続できること。Escで取消。
7. Task右クリック→結果を追加。クリックした時刻が初期値になり、元の到達先・終了時刻を保って別の結果が分岐すること。Task編集でラベル、結果先、分岐時刻を変更する。分岐点へ接続していた因果が時刻変更に追従すること。
8. Task編集に開始・終了・所要時間が表示され、変更対象がState / 分岐点であると明示されること。通常Taskの終了を変えると接続先Stateの時刻も変わること。

## 配置の回帰確認

ドラッグ座標の確認：

- ブラウザの表示倍率を変更し、縦スクロールした状態でも、Alt接続・State移動のプレビュー線がドラッグ開始点から現在のポインターまで描かれること。接続先時刻・移動後時刻も同じ座標に対応すること。
- ドラッグ途中でスクロールしても、開始点は図上の元の位置に留まり、終点はポインターへ追従すること。操作終了後にプレビューが残らないこと。

1. 同時刻の結果Stateを追加し、上下分離してXが変わらないこと。
2. 長い日本語State名を入れ、点のサイズは一定で周辺文字が改行・省略されること。Tooltipは全文を示すこと。
3. 上Actor→下Actorの因果が円の下側→上側へ、逆は上側→下側へ接続すること。
4. 始点だけ共通、終点だけ共通、両方共通、途中区間共通の因果を追加。経路が有限範囲で分散し、意味を持つ端点のXが変わらないこと。

## 階層・選択・コピー

1. Actor / 子Actor / 子Groupを作る。ドラッグで上下順序変更・親変更。循環は禁止されること。
2. Ctrl / ⌘＋Actorクリック→まとめる→Group解除を確認。Stateを持つGroupの解除はActor自身を残すこと。
3. Groupを折りたたみ、子Actorの行が消え、子孫のState・Taskが親Actorの色・共通タイムラインへ投影されること。コンパクトでは28px間隔でState名がTooltipへ移り、通常間隔では元の間隔とState名に戻ること。1本表示では全Stateが同じYになり、同時刻の円・重なる活動線が統合され、活動のない時間を線で埋めないこと。集約要素のダブルクリックで展開すること。内部の因果線だけが消え、外部との接続は元の時刻で残り、展開すると元へ戻ること。折りたたんだ子Stateを時間方向へドラッグしてもActorが変わらないこと。
4. Ctrl / ⌘＋クリック、矩形選択で複数Stateを選ぶ。一括移動・複製・削除、Undo / Redoで戻せること。
5. Actor / GroupをCtrl / ⌘＋Dで再帰複製。子Actor、State、Task、junction、BindingのIDが再発行され、内部因果だけがコピーされること。
6. Ctrl / ⌘＋C / X / Vで文書内貼り付け。元Actorが残るStateコピーと、Actorを含むコピーの両方を確認する。

1. ズームしても横幅が1画面内。スライダー、時間範囲、Space＋ドラッグでパン、全体で復元。
2. Inspector・検索・編集ダイアログが画面内に収まり、開閉できること。F検索で対象の祖先Groupが開き、時刻範囲が移動すること。
3. Technologyを登録し、actor / state / task / causalLinkへBinding。背景・枠付き吹き出し、Tooltip、カタログの依存先を確認。狭い表示幅と多数のBindingでも吹き出しがノード・文字・経路線・他の吹き出しに重ならず、必要に応じて行が広がること。引き出し線が矩形を避け、太い塗り潰しにならないこと。技術フィルタをオフにすると余白が戻ること。
4. Technology / Gap / Causality Viewへ変更。Task分類を変えても正負以外の線種・種類別色が増えないこと。
5. 敵Taskを選び、観測→判断→指令→攻撃の経路、時刻窓、技術Gapを確認。経路上の技術をresearch / gap / unknownへ変更して未充足になること。
6. negative因果にTask終了より遅い到達timeを設定。「到達が遅すぎます」とSOME未充足を確認する。
7. quiet / technology / causalLinkのフィルタが表示だけに作用すること。

## 保存・出力・エラー

1. JSON保存→読込でState.time、Task分岐、正負因果、Actor階層、Technology、Viewが維持されること。
2. v1、参照切れ、時間逆行、重複ID、8MiB超のJSONは分かりやすく拒否し、編集中文書を壊さないこと。
3. ブラウザ再読込でv2自動保存を復元。保存不能時には保存済みと表示しないこと。
4. ズーム・折りたたみ・フィルタ中にSVG / PNGを出力。全期間・全階層が入り、編集Viewは変わらないこと。
5. SVGを別のブラウザ・画像ビューアで開き、波線・矢印・日本語が表示されること。PNGは白背景で切り捨てがなく、波線と文字が読めること。
6. 大きな図でPNG寸法が16,384px／辺・3,200万画素以内となり、全体が縮小されること。
7. 読込・サンプル置換後もUndo可能。失敗した編集・PNG変換はエラーを表示し、成功と誤表示しないこと。

表示設定の折りたたみ表示がJSON保存・読込とUndo / Redoで保持されること。SVG / PNGの全階層出力はこの設定によらず同じ内容になること。

## Actor色と波線の矢じり

1. Actorをダブルクリックして色を変更し、State・Task・結果線と、そのActorを起点とする正負の因果線が同色になること。選択やGap強調でも線の色を保持すること。
2. 色のUndo / Redo、複製、JSON保存・読込、SVG / PNG出力を確認すること。
3. 水平・垂直・斜め・折れ曲がる負の因果で、矢じりが波の接線ではなく経路末尾の方向を向くこと。

## 因果作用からの分岐追加

1. 正／負の因果をTask途中へ接続し、因果線の右クリックまたは詳細パネルの「この作用による分岐を追加」を開く。受け手Actor・Task・到達時刻が入力済みで、結果ラベルが一律NGにならないこと。
2. 作用時刻が10.5などスナップ単位に合わない場合も、白丸から正確な時刻を引き継ぐこと。複数作用が同時刻なら作用名で選べること。
3. 新規Stateを作る場合は結果名と必要なら出現時刻を指定する。既存Stateを選ぶと新規入力欄が隠れ、余計なStateが作られないこと。
4. 追加後も元の通常到達先、Task終了、後続作用の介入時間窓判定が変わらないこと。同時刻の結果は同じ白丸に集約されること。
5. Undoで新規Stateと分岐が一緒に戻り、因果線自体は残ること。Redo・JSON保存読込で復元されること。
6. キャンセル、分岐以前の結果State指定、Task期間外の作用では文書が勝手に変更されないこと。期間外は時刻かTask期間の編集を案内すること。
