# version 3 手動確認

1. index.htmlを開き、沿岸・階層・研究・教材・Simulation例をそれぞれ読み込む。
2. Stateから別Stateへ接続。同ActorならTask、別Actorなら作用線。TaskやActorから接続を開始できないことを確認。
3. Taskメニューで分岐と結果Stateを追加し、別ActorのStateから白丸へ接続。Taskの任意地点への接続では、作用分岐・結果・作用線を一括で作成する画面が開く。適用前の取消で文書・保存・Undoが変わらない。
4. 作用編集の端点はState/junctionだけ。結果Stateと基準伝搬時間を変更し、関連時刻の差分と一括更新、負の所要時間などの詳細エラーを確認。
5. Taskと作用線のCDF表に保持率qを入力。入力品質qを変えてプレビューの帯を確認。最終p<1で未達確率を確認。
6. State AND/OR、Task品質入力AND/OR、固定時間の保持率を保存し、Undo/Redo・コピー・削除の参照を確認。
7. 表示設定で暗黙の開始依存を表示。対象Taskの追加開始条件も表示され、通常の作用線と区別できることを確認。
8. 循環を含むJSONを読み込んだ時に、依存経路・JSON path・該当JSONが表示され、既存文書が維持されることを確認。
9. Simulation例の少量の開発試行で分岐、未達、未発生、終了後の不成立を確認。成功率の実性能への解釈はしない。
10. 結果表示の割合・線幅、SVG/PNG・JSON出力、各View・折りたたみ・技術表示を確認。基準時刻と設定が結果表示で書き換わらないことを確認。

## エラーのあるJSONの診断表示

読み込み時のモデル検証エラーは図の表示を止めません。描画可能な項目を残し、問題のState・Task・作用線付近に赤い吹き出しを表示します。「コピー」でエラーメッセージ・JSONパス・問題JSONをまとめてコピーできます。クリップボードAPIを使えない場合は従来のコピー処理を試し、失敗時は全文を選択してCtrl+C / ⌘Cを案内します。本文の手動選択と右クリックも利用できます。吹き出し内をスクロールすると、エラーメッセージ、元JSONのパス、問題JSONを確認できます。描画できない参照切れの線は省き、起点付近または図の上部に診断を表示します。

元JSONは保持します。診断用の範囲補正や項目除外は保存に反映しません。「JSON保存」は元JSONを出力し、ブラウザの既存保存データは上書きしません。診断表示中は編集・シミュレーションを停止します。元JSONを修正して再読み込みするか、Undoで前の正常な文書に戻ります。JSONの構文が壊れている場合は図示できず、従来どおり構文エラーを表示します。

確認: 時刻不整合、欠落した起点State、欠落した到達先State、欠落した配列、Actorの親循環を含むJSONを読み込む。正常部分・吹き出し・元JSON保存・Undo・正常文書の再読み込みを確認します。最初のモデル検証エラーと、描画できない項目の診断を表示します。元JSONを修正し再読み込みすると次の検証エラーを確認できます。

## 全CDFの自動感度分析と図・グラフの対応

シミュレーション例を開き、Simulation →「全CDFの自動感度分析」→「全CDFを分析」を実行します。Task・作用線の実行CDFすべてにグラフが生成されること、改善効果と劣化への弱さで順位を切り替えられることを確認します。番号・色を図とグラフで照合し、分析図の番号からグラフへ、グラフの「シナリオ図で確認」からメイン図へ移動します。メイン図の番号から分析画面へ戻り、同じ対象が強調されることを確認します。分析JSON保存、中断、試行数超過の案内、計算条件の変更時に変更前の結果が保持され、再実行で比較できることを確認します。名前・備考だけの変更では結果を保持します。


## 人が作成する操作フロー

新規→登場主体→活動→次の活動→相互作用→達成目標→実行準備の順で、ショートカットを使わずに作成します。候補の強調・不正な接続の理由・分岐の通常継続率・AND/ORのプレビューを確認します。

Stateの移動で後続時間の保持と基準時刻の保持を切り替え、ドラッグの仮表示・Undo一回・複数Stateの移動を確認します。Taskの開始/終了アンカー、分岐のみのTaskの所要時間、途中成果の分割と品質、秒→時間→秒の換算を確認します。

CDFの点をマウス・キー・表で編集し、時間順序と確率の単調性、ひな型・複製・低品質/高品質設定・qスライダーを確認します。追加開始・品質・中止条件は図から選択します。長い編集画面でも適用・キャンセルとタイトルが画面内にあることを確認します。

検索・関連先・前後State・選択へ移動・折りたたみ時の全体概観、Actor移動の親子化/並べ替え位置、複製・削除の範囲表示を確認します。

複数文書を作成して切り替え、別案複製・保存時点の作成・再読込・復元を確認します。時刻診断の修正案を適用する前は原JSONが残り、適用後も修正前の保存時点に原文が残ることを確認します。

実ブラウザの再現手順は [authoring-workflow.md](authoring-workflow.md) と `tests/browser-authoring.cjs` を参照します。
