# version 3 手動確認

1. index.htmlを開き、沿岸・階層・研究・教材・Simulation例をそれぞれ読み込む。
2. Stateから別Stateへ接続。同ActorならTask、別Actorなら作用線。TaskやActorから接続を開始できないことを確認。
3. Taskメニューで分岐と結果Stateを追加し、別ActorのStateから白丸へ接続。Taskの任意地点への接続は成立しない。
4. 作用編集の端点はState/junctionだけ。結果Stateと基準伝搬時間を変更し、整合しない場合は詳細エラーを確認。
5. Taskと作用線のCDF表に保持率qを入力。入力品質qを変えてプレビューの帯を確認。最終p<1で未達確率を確認。
6. State AND/OR、Task品質入力AND/OR、固定時間の保持率を保存し、Undo/Redo・コピー・削除の参照を確認。
7. 表示設定で暗黙の開始依存を表示。対象Taskの追加開始条件も表示され、通常の作用線と区別できることを確認。
8. 循環を含むJSONを読み込んだ時に、依存経路・JSON path・該当JSONが表示され、既存文書が維持されることを確認。
9. Simulation例の少量の開発試行で分岐、未達、未発生、終了後の不成立を確認。成功率の実性能への解釈はしない。
10. 結果表示の割合・線幅、SVG/PNG・JSON出力、各View・折りたたみ・技術表示を確認。基準時刻と設定が結果表示で書き換わらないことを確認。
