# 時間・品質のイベントシミュレーション

モデルの詳細は[data-model.md](data-model.md)、生成手順は[llm-simulation-generation.md](llm-simulation-generation.md)を参照する。

ブラウザのSimulationメニューから成功State、AND/OR、期限、試行数、Seedを設定する。実行は明示操作で開始する。各Taskを1回実行し、到達Stateを経由して時間・品質を伝搬する。

Taskと作用線は共通のCDF・品質保持率を使う。CDF表は「入力qの曲線」と各点の「所要時間t、累積到達確率p、品質保持率q」を編集する。最後のpが1未満なら残余は不達。q_out=q_in×保持率。固定時間でも品質保持率を指定できる。曲線が1本なら全入力品質に共通、2本以上なら入力q=0と1を含める。プレビュー入力qは文書や上流品質を上書きしない。

時間モデルをFIX/CDFから選び、グラフの点をマウス・矢印キーで編集するか、数値表を使う。ひな型・既存CDFの複製・低品質/高品質の曲線作成を利用できる。仮置きと根拠は備考に残す。時間順序と累積確率の単調性を保持し、品質保持率は表で編集する。入力qのスライダーはプレビュー専用。基準時刻・所要時間の編集でCDF点の時間は自動変更しない。

State合流はANDなら全到達を待って最小q、ORなら成立時点に到達済みの最大q。初期Stateのqは既定1。Taskは開始時に品質を確定し、実行中には変更しない。品質q=0で到達することと、不達は区別する。

作用線はStateからState・明示的分岐点へ接続する。分岐作用の起点Stateは対象Taskの実際の開始を暗黙に待つ。必須の開始許可は品質計算へ加えず、ORの通常入力とも分離する。対象が開始不能なら作用も発生しない。開始前到達は内部不整合、終了後は不成立。同時刻の発生・到達は受け手の完了より先に処理する。

表示設定の「暗黙の開始依存」で必須開始条件を破線表示できる。循環は静的検証で依存経路・関連JSONを表示する。複数Taskへ作用する同一の発生元Stateは全対象の開始を待つ。

結果には成功率、95%区間、到達時間P50/P90、Taskの入力/出力qを含む第1試行履歴、作用の伝搬時間・出力q・未達・未発生・不成立が含まれる。割合の分母は全試行。結果表示は線幅＋割合で基準図へ反映し、文書の時刻やモデルは書き換えない。結果JSONには入力文書を同梱する。

感度分析はTaskの固定所要時間または入力qへの介入を評価する。品質は大きいほど良いため、qの単調な評価では下限、時間では上限を報告する。非単調なら達成範囲だけを示す。推定値・区間は評価範囲内の標本推定で、実在装備の能力を保証しない。

[シミュレーション例](../examples/simulation.json)は架空の単一ミサイル・観測・管制・二層迎撃。指令と対象軌道条件をAND合流させ、発射後の迎撃品質を伝搬する。q・時刻・CDFは説明用の仮定。

## 全CDFの自動感度分析

Simulationの「全CDFの自動感度分析」から、実行が有効な全Task・作用線のCDFをまとめて分析できます。各点の試行数と評価点数を指定し、入力品質q=0〜1を等間隔で評価します。基準シナリオを1回評価した後、対象CDFを1つずつ変更して同じSeedで比較します。固定時間モデルと表示専用の作用線は対象外です。

変更するのは対象CDFに入力する品質qです。CDFの各点の品質保持率・確率は変更しません。対象の成立・開始条件を維持し、変更後の実行時間・出力品質を後続へ伝搬します。TaskではTask開始時、作用線では作用発生時に入力qを介入値へ固定します。元JSONは変更しません。

結果には対象ごとのq–Mission成功率グラフ、各点の95%信頼区間、基準成功率の破線、改善・劣化のランキングを表示します。

- 改善効果: q=1の成功率−基準成功率。
- 劣化への弱さ: 基準成功率−q=0の成功率。
- 差はパーセントポイント（pt）。負の差もそのまま表示します。改善効果・劣化への弱さで順位を切り替えられます。

各CDFには番号と色を付け、グラフ、ランキング、分析画面内のシナリオ図、メインのシナリオ図で共通に表示します。図の番号または対象を選ぶと対応グラフと線が強調されます。グラフの「シナリオ図で確認」はメイン図を展開して対象を選択します。メイン図の番号から分析画面へ戻れます。図のレイアウト変更では結果を保持し、文書のモデル変更時には分析を無効化します。

分析は中断でき、入力文書と全結果をJSON保存できます。試行数×評価点数×対象数の総処理量には上限があり、超過時は試行数・評価点数を減らすよう案内します。

分析カードから対象の設定を開けます。名前・備考・色・技術・表示のみの変更では結果を維持します。計算条件を変更すると現在の図への適用を解除し、変更前の結果と旧入力を残します。旧結果をJSON保存でき、再実行後は前回との基準成功率の差を比較できます。シミュレーションも同じ方針で変更前の結果を保持します。変更前の結果を現在の入力に対する結果として扱いません。

ランキングは単独変更による標本推定です。複数CDFを同時に改善した場合の相互作用は評価しません。基準の入力qは上流の抽選結果によって試行ごとに変わり得るため、基準成功率の破線は特定の横軸qに対応する点ではありません。品質向上が成功率向上へ単調に結び付かない分岐でも、得られた曲線と符号付きの差を表示します。
