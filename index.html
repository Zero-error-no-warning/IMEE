操作ガイド

Stateは到達時点、Taskは時間をかけて行う活動です。

追加・接続
Actor行の空白をダブルクリックしてStateを追加。Alt / Option＋State・Taskのドラッグ、または選択後にCキーで接続。同じActorのState間はTask、それ以外は因果リンクになります。正・負は作成後のポップアップで選びます。
分岐
Taskの右クリック→「結果を追加」。分岐時刻・結果ラベル・接続先Stateを指定。同じ時刻の結果と外部因果は小さい白丸に集約します。通常Taskには中間ノードはありません。
移動・選択
Stateの点をドラッグして時刻を変更。左右キーでも移動。Ctrl / ⌘＋クリックで複数選択、空白ドラッグで矩形選択。Ctrl / ⌘＋ドラッグは複製移動。
Actor階層
Actorをドラッグし、行の中央で子Actorに、上端・下端で並べ替え。複数Actorを選んで「まとめる」、右クリックでGroup解除。三角で折りたたみます。
画面と時刻
＋ / −は表示する時間範囲を変更し、横幅を固定します。スライダーまたはSpace＋ドラッグでパン。詳細パネルは開閉可能。Fで検索。
キーボード
Ctrl / ⌘＋ZでUndo、Shift＋ZでRedo、Dで複製、C / X / Vで文書内コピー・切り取り・貼り付け、GでGroup化、Shift＋Gで解除、SでJSON保存。Deleteで削除、Enterで編集、Escで接続取消。
Technologyと分析
右クリックまたは詳細パネルで技術を関連付け。Technology / Gap Viewで詳細、Causality Viewで因果を強調。敵Taskを選ぶと介入時間窓・方向付き経路・未成熟技術を確認できます。役割は分類とStateの判断欄で明示してください。
保存・出力
ブラウザ内に自動保存。JSONはversion 2専用です。右上メニューから全期間・全階層のSVG / PNGを出力。読込・サンプル置換もUndoで戻せます。

横位置は常に時刻です。重なるStateは同じActor内で上下に分離します。予定・案は明示タグで表示。線種は正の実線と負の波線だけです。
