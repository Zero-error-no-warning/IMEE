操作ガイド

時間が位置を決め、状態がミッションを語ります。

Stateを追加
Actorの行の空白をダブルクリック。Sキーでも追加モードへ。
移動・複製・伸縮
本体をドラッグ。Ctrl / ⌘ + ドラッグで複製。両端のハンドルで期間を変更。
遷移を結ぶ
Tキー → 同じActorのStateを2つ選択。間隔は遷移に要する時間です。
作用を結ぶ
Iキー → 別ActorのStateを2つ選択。発生・到達時刻を確認して適用。
予定遷移を阻止
Bキー → 作用元State → 点線の予定Transition。阻止時刻と妨害後のStateを設定。
Actorの並べ替え
左のActor名をドラッグ。または詳細パネルの上下ボタン。
編集・削除
ダブルクリック、右クリック、または詳細パネル。Deleteで削除。
キーボード
V 選択 / Esc キャンセル / Ctrl+Z 元に戻す / Ctrl+Shift+Z やり直す。選択したStateは ← → で移動、Shift+← → で終端を伸縮。Enterで編集。
保存
このブラウザに自動保存。持ち出し・バックアップはJSON保存。メニューからSVG出力。

重なるStateはActor内で自動的に段を分けます。実際と予定は手動指定です。妨害登録によって後続の予定全体を自動変更することはありません。
