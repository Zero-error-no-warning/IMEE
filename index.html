操作ガイド

時間が位置を決め、状態がミッションを語ります。

Stateの追加・編集
Actor行の空白をダブルクリックして追加。項目のダブルクリックで編集。右クリックでも操作できます。
接続（切り替え不要）
Alt（MacはOption）を押しながらState本体から接続先へドラッグ。同じActorのStateなら遷移、別Actorなら作用、予定Transitionなら妨害になります。Stateを選択してCキーを押し、接続先をクリックしても接続できます。
移動・複製・伸縮
State本体をドラッグ。Ctrl / ⌘ + ドラッグで複製。両端で期間を伸縮します。
グループ・入れ子
「＋ グループ」またはActorの右クリックから子Actor・子グループを追加。編集の「親Actor / グループ」で階層を指定。左の三角で折りたたみます。
Actorのドラッグ
移動先のActor名の中央にドロップすると子になります。行の上下端にドロップするとその前後に並べ替えます。子孫は一緒に移動します。
横幅を固定して拡大
＋ / − は表示する時間範囲を拡大・縮小します。下部のスライダー・矢印・時間範囲ボタンで表示時間を移動・指定できます。「全体」で全期間に戻ります。
画面内の操作
Space + ドラッグで時間範囲と上下表示を移動。詳細パネルは右下から開閉できます。検索・設定・編集もこの画面内で行います。
キーボード
C 選択したStateから接続 / F 検索 / Esc 取消 / Delete 削除 / Enter 編集 / Ctrl+Z 元に戻す / Ctrl+Shift+Z やり直す。選択したStateは ← → で移動、Shift+← → で終端を伸縮します。
複数選択・コピー
Ctrl / ⌘ + クリックで選択を追加・解除。空白からのドラッグで矩形選択。Ctrl / ⌘ + DでState・Actor・Groupを複製、C / X / Vで文書内コピー・切り取り・貼り付け。Gで選択ActorをGroup化、Shift+Gで解除します。
技術と経路
上部でTechnology / Gap / Interaction Viewを選択。詳細パネル・右クリックから技術を関連付けます。敵Transition選択で候補経路と時間窓を確認。判断段階はStateの役割欄で指定します。経路評価は登録した因果・技術・時刻による構造評価です。
保存
このブラウザに自動保存。バックアップはJSON保存。右上メニューからSVG・PNG出力（全期間・全階層）できます。

重なるStateはActor内で自動的に段を分けます。実際と予定は手動指定です。妨害登録によって後続の予定全体を自動変更することはありません。
