操作ガイド

「新規」から、登場主体→活動→相互作用→達成目標の順で作ります。Stateは到達時点、Taskは時間をかけて行う活動です。上部の「練習する」で手順を確認できます。

追加・接続
活動ボタンまたはActor行の＋で、開始条件・活動・成果をまとめて追加。選択したStateの＋接続や接続ボタンを使えます。Alt / Option＋Stateのドラッグ、または選択後にCキーで接続。同じActorのState間はTask、Stateから別ActorのState・既存の分岐点へは作用線になります。
分岐
「分岐」で方式・時刻・結果・確率・遅延を指定。活動上に作用を結ぶと分岐と作用を一括で作成できます。「途中の成果を追加」で活動を分割してStateを置けます。
移動・選択
Stateの点をドラッグして関連時刻をまとめて変更。Shiftで後続時刻を維持します。詳細でも変更をプレビューでき、左右キーでも移動。Ctrl / ⌘＋クリックで複数選択、空白ドラッグで矩形選択。Ctrl / ⌘＋ドラッグは複製移動。
Actor階層
Actorをドラッグし、行の中央で子Actorに、上端・下端で並べ替え。複数Actorを選んで「まとめる」、右クリックでGroup解除。三角で折りたたみます。
画面と時刻
＋ / −は表示する時間範囲を変更し、横幅を固定します。スライダーまたはSpace＋ドラッグでパン。詳細パネルは開閉可能。選択へ移動・全体概観・前後State・関連先へ移動できます。Fで名前・備考・IDを横断検索。
キーボード
Ctrl / ⌘＋ZでUndo、Shift＋ZでRedo、Dで複製、C / X / Vで文書内コピー・切り取り・貼り付け、GでGroup化、Shift＋Gで解除、SでJSON保存。Deleteで削除、Enterで編集、Escで接続取消。
Technologyと分析
右クリックまたは詳細パネルで技術を関連付け。Technology / Gap Viewで詳細、Causality Viewで因果を強調。敵Taskを選ぶと介入時間窓・方向付き経路・未成熟技術を確認できます。役割は分類とStateの判断欄で明示してください。
保存・出力
「文書」で複数文書・別案を管理。「保存時点」は文書ごとに最新20件を復元できます。ブラウザ内に自動保存。JSONはversion 3専用です。右上メニューから全期間・全階層のSVG / PNGを出力。読込・サンプル置換もUndoで戻せます。

横位置は常に時刻です。重なるStateは同じActor内で上下に分離します。CDF有効のTask・作用線は実線、所要時間・伝搬時間固定（FIX）のTask・作用線・分岐後の線は二重線です。表示のみの作用線は単線です。作用線の起点はState、到達先はStateまたは分岐点です。Task・分岐のラベルは線上の枠付き、作用ラベルは線と同色の下線付きです。CDF有効Task・作用線をホバーすると、入力qの変化幅を帯グラフで確認できます。設定では点をドラッグ・矢印キー・表で編集します。qスライダーはプレビュー専用です。

Mission Simulation

感度分析 / 要求逆算

同じSeedで対象Taskの性能だけを変え、Mission成功率への影響を評価します。時間固定はTaskの達成を仮定する介入で、実CDFの未達確率を除きます。要求は評価範囲内での推定です。

全CDFの自動感度分析

実行対象の全Task・作用線のCDFについて、入力品質qを0〜1に固定してMission成功率を比較します。他の条件は維持し、出力を後続へ伝搬します。番号と色は図・グラフで共通です。番号や対象をクリックすると双方を強調します。

評価するのは対象への入力品質の変更です。技術成熟度の変更や、CDF自体の高速化・未達低減を直接評価するランキングではありません。
